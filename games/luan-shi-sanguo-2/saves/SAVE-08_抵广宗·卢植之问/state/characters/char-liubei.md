# 刘备（字玄德）

> 历史/演义人物以 library 人物卡为参照底，此处只记本局实况。

## 身份（本局时点）

- 刘备，字玄德，二十八，涿郡楼桑村，汉室宗亲；少年师事卢植于缑氏山（与公孙瓒同门）
- 三月初七桃园结义（与关羽、张飞）；**刘焉认其为侄**（三月十一）；**暂署别部司马，领义兵一千五百从征青州**（三月十八令）
- 鉴定面板: 膂力中/身法中/根骨上/学识中上/**器量：大**

## 与陈翊（臣·同袍）

- 酒肆大失败→缑氏山暗钩→接纳共谋→**堂上之盟："桃园之盟是兄弟之义，堂上之盟是同袍之义，备此生必不相负"**
- 旬月验证后："备亦不复疑……只是备更信另一句——可验不可问。备，仍然不问。"
- 大兴山全用其策；抚恤收编从其议而自改一笔（裹挟百姓给粮遣归）
- 樊氏事："从长计议，备与公共担"；志向已对陈翊白："黄巾是病之发非病之本……能医一郡医一郡，能医一国医一国"

## 认知边界

- 知：陈翊有非常之知（三次应验）、识字通经、组织之才、樊氏案全貌；**仍不知穿越/系统/演义，且主动不问**
- 知陈翊重伤初愈（愈前忌久战）

## 主持人注记

- 喜怒不形于色，善下人；裁夺果断，能改属下之策而不夺其功；看长线
- 当前势：太守之侄+新胜之名+一千五百兵——青云之始，亦招忌之始
