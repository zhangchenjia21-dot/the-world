## 主角

- 姓名: 陈翊（宿主之名；游侠无字，道上人称"陈四"）
- 宿主年龄: 21 岁，男
- 宿主身份: 幽州涿郡岌岌无名的游侠（县吏名册上挂号的"轻侠"）
- 宿主特质: 身体素质极好（马上步下皆能，环首刀娴熟，膂力过人）；识字（少年时收留党锢避祸北来的南阳老儒，随学三载，粗通经义——从不示人）
- 宿主旧案: 184 年去年冬为受欺压炭农出头，打断涿郡豪族樊氏家奴头目杜横一臂，案子未结，樊氏寻仇
- 穿越者: 现代退役武警（两年义务兵），熟知《三国演义》，正史只知大概；自此以"陈翊"为名
- 穿越形式: 魂穿（意识进入宿主身体，宿主记忆以碎片/本能形式部分残留）
- 系统: 成长型系统（任务合同 / 系统货币与商城 / 抽奖 / 系统空间 / 鉴定，逐步解锁；开局仅低级鉴定 + 小型系统空间）
- 落点: 184 年三月上旬 · 幽州涿郡——宿主前夜被樊氏家奴围殴濒死，穿越者带伤醒来；同日，刘焉招募义兵榜文张出

## 存档策略

- 策略: **仅重大阶段切换（里程碑）自动存档 + 玩家随时手动「存档」**
- 回合定义: player turn = 一次玩家输入 → 一次 GM 正常回复；后台 maintenance step 不计回合
- 里程碑: THREADS 大批量结算、势力归属变化、主角身份跃迁、重大时间跳跃
- 自动存档保留: 最近 5 个，超出滚动删除；手动存档永不自动删除
- 快照内容: COMPOSITION.md + state/ + mechanics/ + story/ + memory/ 全量复制（不含 saves/ 与 library/）；每个 SAVE 带 META.md（回合数 / 游戏内日期 / 触发原因）
- 注意: Persistent State ≠ Save Point——无论选什么策略，后台维护都持续更新 state/、mechanics/、story/、memory/
