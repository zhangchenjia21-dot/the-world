# mechanics｜本局机制运行状态

> `library/mechanics/` 是规则源（不可变资产，规定机制怎么运作）；本目录只存**本局的长期运行状态**（规定这局里这个机制现在是什么）。
> 架构边界：Expansion Pack 声明「哪些事实值得长期记住」；World Core 决定「这些事实存到哪里」。Expansion 不声明具体文件路径。
> 只有真正产生了长期状态的机制才建档；裁定型机制（只增加判定方式、无长期状态）永不建档。
