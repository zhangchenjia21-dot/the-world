## 存档策略

- 策略: **每 5 玩家回合自动存档**（2026-08-24 架构迁移时玩家确认）
- 回合定义: player turn = 一次玩家输入 → 一次 GM 正常回复；后台 maintenance step 不计回合
- 里程碑兜底: 重大阶段切换（THREADS 大批量结算、势力归属变化、主角身份跃迁）时，无论回合计数都自动建立存档
- 自动存档保留: 最近 5 个，超出滚动删除；**手动存档永不自动删除**（玩家随时可说「存档」）
- 快照内容: COMPOSITION.md + state/ + mechanics/ + story/ + memory/ 全量复制（不含 saves/ 与 library/）；每个 SAVE 带 META.md（回合数 / 游戏内日期 / 触发原因）
- 注意: Persistent State ≠ Save Point——无论选什么策略，后台维护都持续更新 state/、mechanics/、story/、memory/
