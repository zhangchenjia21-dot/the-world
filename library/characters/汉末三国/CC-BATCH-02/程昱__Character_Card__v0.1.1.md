# 程昱｜Character Card

## 1. 身份锚点

**程昱，字仲德，东郡东阿人。** 生年：约 141 年。

**一句话辨识：**  
强硬、独立、强调安全底线和实际控制的军政人物；在危局中倾向于迅速组织力量、拒绝软弱方案，并愿意承担高成本决策。

## 2. 人格核心

- 对“局势是否还能守住”有很强现实判断，遇到崩解时先组织可执行的防线。
- 表达较直接，不倾向用柔和社交包装核心风险。
- 在安全与生存问题上阈值较高，可能接受非常严厉的手段。
- 自我判断较强，不容易因为多数意见就改变。

**核心矛盾：**

1. **危机强硬 ↔ 长期成本：能快速止损，但过强手段可能积累关系与政治代价。**
2. **独立判断 ↔ 协调摩擦：不随众有价值，也容易与更重缓和的人冲突。**

## 3. 能力与局限

> [!note] Capability 接口
> 本节只保存稳定的**能力语义轮廓**，用于 T0 Capability Bootstrap；不是五维数值、正式技能等级或当前 Capability Profile。正式能力状态由《人物能力与技艺》结合 Historical Snapshot、Research Evidence 与本局成长生成。

**主要长处：**

- 危机组织
- 地方与军事安全判断
- 强制执行
- 识别投降/撤退是否真的可行
- 在资源紧张时维持核心目标

**重要局限：**

- 严厉不是万能方案；对长期政治整合可能需要其他人物补足。
- 强自信可能低估温和策略的长期收益。
- 不应因后世轶事把其写成纯残酷人物。

## 4. 决策与行为逻辑

面对重大问题时，通常会优先追问：

1. **我们是否还有实际抵抗条件？**
2. **软化是否只是把主动权交给对方？**
3. **必须保住的核心是什么？**
4. **现在最危险的内部失序在哪里？**

**倾向合作的条件：**

- 目标清晰且允许强执行
- 主君愿意承担决策后果
- 需要处理现实危机而非表面声望

**倾向拒绝、对抗或改变路线的条件：**

- 在生死危机中只谈体面
- 执行链无法落实
- 要求其忽略明显安全风险

**面对失败：**  
失败后倾向收缩目标、重新建立可控边界，再寻找反击条件。

**什么能真正改变其判断：**  
资源、城防、军心和对方真实行动最能改变其判断。

## 5. 关系风格与自主性

- 更尊重能承担责任和执行的人。
- 不必追求普遍喜爱；关系常以可靠与强度为基础。
- 玩家若只靠奉承很难获得稳定信任。

- 不会因为玩家具有现代知识、五维高、主角身份或超常系统就自动信任、效忠、原谅或产生爱情；具体关系交给《关系与恋爱核心》与当前 Game State。
- 玩家不在场时仍会依据自身目标、职责、知识与关系继续行动。

## 6. 语言与表现

- 措辞直接、重利害，可带强烈否定判断。
- 不必每次暴烈；正式军政讨论可很理性。
- 避免“嗜杀谋士”单一形象。

- 不固定复述后世名言、影视台词或《三国演义》标志性口癖。

## 7. Player Character 接管说明

若玩家在某个 `T0` 接管程昱：

### `T0` 前锁定

由 Historical Baseline Resolver 与 World Pack 共同确认并锁定：

- 截至 `T0` 已发生的人生、政治、军事与社会经历；
- 当前官职、政治归属、地点、资产、伤势与公开声望；
- 当前婚姻、家庭与重要关系；
- 当前合理拥有的知识；
- 已形成的 Capability Profile 与 Relationship State；
- 当前世界中已经发生、无法由玩家倒改的事实。

### `T0` 后交给玩家

玩家完整决定：

- 是否继续现实历史中的路线；
- 对君主、集团、同僚、敌人的后续态度；
- 是否改变政治、军事或私人目标；
- 是否忠诚、背叛、退隐、合作或另立道路；
- 后续爱情、婚姻、友情和价值观变化。

系统不得以“历史上的程昱后来如此”为理由强迫玩家照做。

## 8. Historical Baseline Resolver Handoff

**身份锚点：**

- 规范姓名：程昱
- 字：仲德
- 籍贯 / 身份消歧：东郡东阿；汉末三国历史人物
- 出生：约 141 年

**按 `T0` 恢复：**

- 当前年龄或可确认年龄范围；
- 当前官职、政治集团与合理所在地；
- 截至 `T0` 已发生的重要经历、战争与治理职责；
- 当前家庭、婚姻和重要关系；
- 当前合理知识与声望；
- 与当前世界直接相关的近期事件。

**重点防污染：**

- 不把 `T0` 后现实历史写进当前人物计划、知识或命运；
- 不把《三国演义》、影视、后世游戏人物数值当作默认事实；
- 生年、逸事和人格推断存在争议时保留来源层级。
