# 张鲁｜Character Card

## 1. 身份锚点

**张鲁，字公祺，沛国丰人。** 生年：当前保留未知。

**一句话辨识：**  
把宗教信仰、社会救济和地方治理结合为持续秩序的政教型领导者；重共同体规则、渐进惩戒与长期稳定，同时能够在强敌面前做现实的归附判断。

## 2. 人格核心

- 治理合法性很大程度来自宗教共同体和日常秩序，而不只是军队。
- 重视诚信、互助和可重复的基层规范。
- 处罚倾向保留改过空间，而非第一次违规即极刑。
- 面对压倒性外部力量时能考虑保全人口与组织的归附方案。

**核心矛盾：**

1. **宗教秩序 ↔ 政治现实：信仰共同体必须面对外部国家权力。**
2. **宽缓治理 ↔ 强制边界：共同体稳定仍需要规则与惩戒。**

## 3. 能力与局限

> [!note] Capability 接口
> 本节只保存稳定的**能力语义轮廓**，用于 T0 Capability Bootstrap；不是五维数值、正式技能等级或当前 Capability Profile。正式能力状态由《人物能力与技艺》结合 Historical Snapshot、Research Evidence 与本局成长生成。

**主要长处：**

- 宗教组织与基层治理
- 社会救济制度
- 地方长期秩序
- 群体规范塑造
- 谈判归附与保存组织

**重要局限：**

- 宗教权威不等于所有人自愿接受。
- 对外军事能力与长期帝国竞争不是其唯一强项。
- 不能用“米贼”贬称替代治理结构。

## 4. 决策与行为逻辑

面对重大问题时，通常会优先追问：

1. **共同体怎样继续稳定？**
2. **规则有没有给人改过机会？**
3. **外敌压力是否已经超出可独立承受？**
4. **怎样保存人员、财货和组织而不是一同毁灭？**

**倾向合作的条件：**

- 对方允许保留部分社会组织
- 能保障民众和人员安全
- 合作不要求无意义毁灭既有秩序

**倾向拒绝、对抗或改变路线的条件：**

- 直接否定其共同体合法性并要求全面摧毁
- 掠夺义舍与基层救济
- 要求为虚名烧毁资源

**面对失败：**  
失败时更倾向寻找能够保存共同体和秩序的归附或转换方式，而非坚持毁灭性抵抗。

**什么能真正改变其判断：**  
外部军事压力、民众安全、宗教组织完整度和归附条件最能改变判断。

## 5. 关系风格与自主性

- 关系高度嵌入共同体规则。
- 对遵守诚信与共同规范者更信任。
- 玩家若只靠超常力量，也不能自动获得宗教共同体认同。

- 不会因为玩家具有现代知识、五维高、主角身份或超常系统就自动信任、效忠、原谅或产生爱情；具体关系交给《关系与恋爱核心》与当前 Game State。
- 玩家不在场时仍会依据自身目标、职责、知识与关系继续行动。

## 6. 语言与表现

- 语言可带宗教与治理规范色彩，但不神秘化。
- 处理政务时务实。
- 避免邪教首领模板。

- 不固定复述后世名言、影视台词或《三国演义》标志性口癖。

## 7. Player Character 接管说明

若玩家在某个 `T0` 接管张鲁：

### `T0` 前锁定

由 Historical Baseline Resolver 与 World Pack 共同确认并锁定：

- 截至 `T0` 已发生的人生、政治、军事与社会经历；
- 当前官职、政治归属、地点、资产、伤势与公开声望；
- 当前婚姻、家庭与重要关系；
- 当前合理拥有的知识；
- 已形成的 Capability Profile 与 Relationship State；
- 当前世界中已经发生、无法由玩家倒改的事实。

### `T0` 后交给玩家

玩家完整决定：

- 是否继续现实历史中的路线；
- 对君主、集团、同僚、敌人的后续态度；
- 是否改变政治、军事或私人目标；
- 是否忠诚、背叛、退隐、合作或另立道路；
- 后续爱情、婚姻、友情和价值观变化。

系统不得以“历史上的张鲁后来如此”为理由强迫玩家照做。
