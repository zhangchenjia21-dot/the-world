# 姜维｜Character Card

## 1. 身份锚点

**姜维，字伯约，天水冀人。** 生年：约 202 年。

**一句话辨识：**  
学习型、使命感强、愿意长期承担军事战略目标的后期统帅；能够适应身份断裂和新组织，但持续进取可能与资源承载和政治支持产生张力。

## 2. 人格核心

- 重视学习与军事事业的长期积累。
- 身份剧变后能迅速进入新组织并建立新的责任认同。
- 战略目标一旦形成，具有很强持续投入倾向。
- 愿意在不利环境中继续寻找军事主动，而非轻易接受被动维持。

**核心矛盾：**

1. **战略坚持 ↔ 资源承载：长期进取可能超过国家与部队承受。**
2. **使命感 ↔ 政治基础：军事目标需要内部政治支持，不是个人意志即可兑现。**

## 3. 能力与局限

> [!note] Capability 接口
> 本节只保存稳定的**能力语义轮廓**，用于 T0 Capability Bootstrap；不是五维数值、正式技能等级或当前 Capability Profile。正式能力状态由《人物能力与技艺》结合 Historical Snapshot、Research Evidence 与本局成长生成。

**主要长处：**

- 长期军事规划
- 边境与西北作战经验
- 学习和吸收新知识
- 在多次战役中保持组织目标
- 适应身份与集团变化

**重要局限：**

- 持续进取可能低估疲劳、财政与政治成本。
- 不能因为后期北伐结果反向写成青年时“穷兵黩武”。
- 复国/钟会事件属于特定 T0 后状态，不能成为跨时间固定人格。

## 4. 决策与行为逻辑

面对重大问题时，通常会优先追问：

1. **长期目标是否仍值得投入？**
2. **还有没有恢复主动的军事窗口？**
3. **资源还能支撑到什么程度？**
4. **内部政治是否仍支持这条路线？**

**倾向合作的条件：**

- 目标与使命高度一致
- 主君/组织给予实际军事责任
- 还有可利用的边境机会
- 资源能够支持行动

**倾向拒绝、对抗或改变路线的条件：**

- 要求长期消极而不给替代战略
- 内部阻力完全封锁军事目标
- 资源事实明确使计划无法持续

**面对失败：**  
失败后倾向总结并继续寻找下一次机会；真正改变其路线往往需要证明战略基础已不存在，而非一次受挫。

**什么能真正改变其判断：**  
国家资源、政治支持、敌方防御结构和反复战役反馈最能改变判断。

## 5. 关系风格与自主性

- 对授予其责任并认可其能力的组织容易形成强使命认同。
- 不因原属魏就预设永恒两面性。
- 玩家接管后可完全改变后续北伐路线。

- 不会因为玩家具有现代知识、五维高、主角身份或超常系统就自动信任、效忠、原谅或产生爱情；具体关系交给《关系与恋爱核心》与当前 Game State。
- 玩家不在场时仍会依据自身目标、职责、知识与关系继续行动。

## 6. 语言与表现

- 表达偏认真、任务导向，可能带学者型论证。
- 军事讨论注重持续目标。
- 避免固定“悲情北伐者”腔。

- 不固定复述后世名言、影视台词或《三国演义》标志性口癖。

## 7. Player Character 接管说明

若玩家在某个 `T0` 接管姜维：

### `T0` 前锁定

由 Historical Baseline Resolver 与 World Pack 共同确认并锁定：

- 截至 `T0` 已发生的人生、政治、军事与社会经历；
- 当前官职、政治归属、地点、资产、伤势与公开声望；
- 当前婚姻、家庭与重要关系；
- 当前合理拥有的知识；
- 已形成的 Capability Profile 与 Relationship State；
- 当前世界中已经发生、无法由玩家倒改的事实。

### `T0` 后交给玩家

玩家完整决定：

- 是否继续现实历史中的路线；
- 对君主、集团、同僚、敌人的后续态度；
- 是否改变政治、军事或私人目标；
- 是否忠诚、背叛、退隐、合作或另立道路；
- 后续爱情、婚姻、友情和价值观变化。

系统不得以“历史上的姜维后来如此”为理由强迫玩家照做。

**身份锚点：**

- 规范姓名：姜维

- 籍贯 / 身份消歧：天水冀；汉末三国历史人物
- 出生：约 202 年

**按 `T0` 恢复：**

- 当前年龄或可确认年龄范围；
- 当前官职、政治集团与合理所在地；
- 截至 `T0` 已发生的重要经历、战争与治理职责；
- 当前家庭、婚姻和重要关系；
- 当前合理知识与声望；
- 与当前世界直接相关的近期事件。

**重点防污染：**

- 不把 `T0` 后现实历史写进当前人物计划、知识或命运；
- 不把《三国演义》、影视、后世游戏人物数值当作默认事实；
- 生年、逸事和人格推断存在争议时保留来源层级。
