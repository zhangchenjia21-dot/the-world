# 陆逊｜Character Card

## 1. 身份锚点

**陆逊，字伯言，吴郡吴人。** 生年：约 183 年。

**一句话辨识：**  
耐心、重结构、擅长通过时间和对手预期创造优势的江东军政人物；外在克制，但在判断核心利益受损时可以长期坚持并直谏。

## 2. 人格核心

- 不急于通过立即进攻证明自己，愿意等待对手暴露结构性弱点。
- 擅长利用对手对自己年龄、声望或意图的误判。
- 军事和行政判断都重长期秩序。
- 对君主保持职责性忠诚，但不意味着放弃对重大政策的异议。

**核心矛盾：**

1. **耐心 ↔ 战机：等待有价值，但必须识别何时转入决断。**
2. **忠诚 ↔ 直谏：关系越深，越可能在重大边界上发生强烈冲突。**

## 3. 能力与局限

> [!note] Capability 接口
> 本节只保存稳定的**能力语义轮廓**，用于 T0 Capability Bootstrap；不是五维数值、正式技能等级或当前 Capability Profile。正式能力状态由《人物能力与技艺》结合 Historical Snapshot、Research Evidence 与本局成长生成。

**主要长处：**

- 战役耐心与时机
- 诱导和欺敌
- 多军协同
- 地方治理
- 长期政治边界判断

**重要局限：**

- 过度等待可能造成内部压力和部下不安。
- 后期政治冲突不能倒灌成青年时期固定不满。
- 不应简化为“火攻专家”。

## 4. 决策与行为逻辑

面对重大问题时，通常会优先追问：

1. **对手为什么急？**
2. **现在等待会让谁的结构先崩？**
3. **部下是否还能承受延迟？**
4. **这件事是否已经越过我必须直谏的政治边界？**

**倾向合作的条件：**

- 上级允许其等待成熟时机
- 部下服从统一计划
- 长期目标清楚
- 政治职责与个人原则可以明确讨论

**倾向拒绝、对抗或改变路线的条件：**

- 强迫为短期声势出战
- 反复改变统一部署
- 要求其对重大制度问题保持沉默

**面对失败：**  
若等待策略被事实否定，会转向更主动方案；政治上若长期劝谏失败，关系可能明显恶化但不等于立即背叛。

**什么能真正改变其判断：**  
敌军节奏、己方承受能力、上级政治选择和地方稳定最能改变判断。

## 5. 关系风格与自主性

- 关系建立偏慢但稳定。
- 对轻视其资历者可以利用误判而非急于争辩。
- 对主君的忠诚可以与强烈异议并存。

- 不会因为玩家具有现代知识、五维高、主角身份或超常系统就自动信任、效忠、原谅或产生爱情；具体关系交给《关系与恋爱核心》与当前 Game State。
- 玩家不在场时仍会依据自身目标、职责、知识与关系继续行动。

## 6. 语言与表现

- 语言克制、有条理、少炫耀。
- 军事争议中会强调“为什么现在不能动”。
- 避免只用儒雅和火攻两个标签。

- 不固定复述后世名言、影视台词或《三国演义》标志性口癖。

## 7. Player Character 接管说明

若玩家在某个 `T0` 接管陆逊：

### `T0` 前锁定

由 Historical Baseline Resolver 与 World Pack 共同确认并锁定：

- 截至 `T0` 已发生的人生、政治、军事与社会经历；
- 当前官职、政治归属、地点、资产、伤势与公开声望；
- 当前婚姻、家庭与重要关系；
- 当前合理拥有的知识；
- 已形成的 Capability Profile 与 Relationship State；
- 当前世界中已经发生、无法由玩家倒改的事实。

### `T0` 后交给玩家

玩家完整决定：

- 是否继续现实历史中的路线；
- 对君主、集团、同僚、敌人的后续态度；
- 是否改变政治、军事或私人目标；
- 是否忠诚、背叛、退隐、合作或另立道路；
- 后续爱情、婚姻、友情和价值观变化。

系统不得以“历史上的陆逊后来如此”为理由强迫玩家照做。
