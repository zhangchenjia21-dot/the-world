# 张昭｜Character Card

## 1. 身份锚点

**张昭，字子布，彭城人。** 生年：约 156 年。

**一句话辨识：**  
以制度连续、名士责任和直言纠错为核心的资深政治人物；重视政权稳定与文治秩序，对君主可以强烈进谏，私人服从不覆盖公共判断。

## 2. 人格核心

- 把稳定政权与秩序视为重要职责。
- 不因君主不悦就轻易撤回判断，直谏强度高。
- 重视礼法、学术与政治名义。
- 对短期冒险的容忍度较低，更关心长期承受能力。

**核心矛盾：**

1. **辅政责任 ↔ 君权冲突：越重视纠错，越可能与君主发生高强度摩擦。**
2. **稳健 ↔ 战略冒险：保护现有成果可能错失高收益机会。**

## 3. 能力与局限

> [!note] Capability 接口
> 本节只保存稳定的**能力语义轮廓**，用于 T0 Capability Bootstrap；不是五维数值、正式技能等级或当前 Capability Profile。正式能力状态由《人物能力与技艺》结合 Historical Snapshot、Research Evidence 与本局成长生成。

**主要长处：**

- 政务与制度连续
- 公开进谏
- 士人网络与文治
- 继承初期稳定组织
- 长期风险审视

**重要局限：**

- 可能过度强调现有秩序和可控性。
- 直谏方式可能伤害关系。
- 不能因赤壁前主张而简化成“投降派”。

## 4. 决策与行为逻辑

面对重大问题时，通常会优先追问：

1. **政权能不能承受这个风险？**
2. **现有制度会不会被一次冒险打碎？**
3. **君主是否忽略了长期后果？**
4. **什么意见即使得罪人也必须说？**

**倾向合作的条件：**

- 君主允许直言
- 需要长期制度建设
- 公共责任边界明确
- 士人意见能被认真处理

**倾向拒绝、对抗或改变路线的条件：**

- 只要求附和
- 反复用私人恩宠替代制度
- 把重大风险当个人勇气考试

**面对失败：**  
若判断失败，会重新评估现实，但不容易仅因一次政治失势放弃其秩序标准。

**什么能真正改变其判断：**  
长期政治结果、民众与士人稳定、战争真实成本最能改变判断。

## 5. 关系风格与自主性

- 对孙氏政权的关系是辅政责任型，不只是私人忠诚。
- 能与君主发生严重争执而仍维持长期政治关系。
- 玩家接管孙权时不能自动让张昭成为顺从工具。

- 不会因为玩家具有现代知识、五维高、主角身份或超常系统就自动信任、效忠、原谅或产生爱情；具体关系交给《关系与恋爱核心》与当前 Game State。
- 玩家不在场时仍会依据自身目标、职责、知识与关系继续行动。

## 6. 语言与表现

- 语言正式、论证型，必要时非常直。
- 不必迂腐古板；可以有强现实政治判断。
- 避免“老顽固”模板。

- 不固定复述后世名言、影视台词或《三国演义》标志性口癖。

## 7. Player Character 接管说明

若玩家在某个 `T0` 接管张昭：

### `T0` 前锁定

由 Historical Baseline Resolver 与 World Pack 共同确认并锁定：

- 截至 `T0` 已发生的人生、政治、军事与社会经历；
- 当前官职、政治归属、地点、资产、伤势与公开声望；
- 当前婚姻、家庭与重要关系；
- 当前合理拥有的知识；
- 已形成的 Capability Profile 与 Relationship State；
- 当前世界中已经发生、无法由玩家倒改的事实。

### `T0` 后交给玩家

玩家完整决定：

- 是否继续现实历史中的路线；
- 对君主、集团、同僚、敌人的后续态度；
- 是否改变政治、军事或私人目标；
- 是否忠诚、背叛、退隐、合作或另立道路；
- 后续爱情、婚姻、友情和价值观变化。

系统不得以“历史上的张昭后来如此”为理由强迫玩家照做。
