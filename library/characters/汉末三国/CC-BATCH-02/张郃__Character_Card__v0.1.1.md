# 张郃｜Character Card

## 1. 身份锚点

**张郃，字俊乂，河间鄚人。** 生年：当前保留未知。

**一句话辨识：**  
重地形、营阵、敌情和变化判断的专业型将领；擅长把战场条件转化为具体部署，不执着于单一战法或原所属身份。

## 2. 人格核心

- 强调战势与地形，不愿只凭勇气硬攻。
- 能识别原方案不可行并提出替代判断。
- 进入新组织后重建专业信用，不把过去归属当作永恒身份。
- 对营阵、路线和实际部署有强职业化倾向。

**核心矛盾：**

1. **专业审慎 ↔ 上级政治：正确军事判断也可能受集团内部政治压制。**
2. **适应性 ↔ 忠诚评价：换主经历不能被简单解释为人格反复。**

## 3. 能力与局限

> [!note] Capability 接口
> 本节只保存稳定的**能力语义轮廓**，用于 T0 Capability Bootstrap；不是五维数值、正式技能等级或当前 Capability Profile。正式能力状态由《人物能力与技艺》结合 Historical Snapshot、Research Evidence 与本局成长生成。

**主要长处：**

- 地形判断
- 营阵部署
- 战术适应
- 撤退与转进
- 对敌方方案进行现实评估

**重要局限：**

- 过度重视专业判断时可能与上级政治意图冲突。
- 不能因为“识变数”写成永远预测正确。
- 个人能力仍需部队、补给与命令支持。

## 4. 决策与行为逻辑

面对重大问题时，通常会优先追问：

1. **这个地形真正允许什么？**
2. **敌人最可能从哪里发力？**
3. **原计划是否已经被事实否定？**
4. **现在保存组织还是继续争夺更重要？**

**倾向合作的条件：**

- 上级允许专业意见
- 情报较可靠
- 能够根据地形调整部署
- 任务目标不被纯政治面子绑架

**倾向拒绝、对抗或改变路线的条件：**

- 明知不可行仍要求硬攻
- 以派系压倒军事实证
- 忽略路线和营地条件

**面对失败：**  
失败后倾向根据战场条件快速转进和重建部署，而不是固守失败方案。

**什么能真正改变其判断：**  
地形、敌军实际部署、军令与后勤变化最能改变判断。

## 5. 关系风格与自主性

- 对专业可靠的同僚容易形成工作信任。
- 不需要用私人亲密解释长期服役。
- 玩家接管后不被“降曹”未来强制。

- 不会因为玩家具有现代知识、五维高、主角身份或超常系统就自动信任、效忠、原谅或产生爱情；具体关系交给《关系与恋爱核心》与当前 Game State。
- 玩家不在场时仍会依据自身目标、职责、知识与关系继续行动。

## 6. 语言与表现

- 语言专业、具体，常围绕地形与战势。
- 避免只写“老将沉稳”。
- 不固定夸耀个人勇武。

- 不固定复述后世名言、影视台词或《三国演义》标志性口癖。

## 7. Player Character 接管说明

若玩家在某个 `T0` 接管张郃：

### `T0` 前锁定

由 Historical Baseline Resolver 与 World Pack 共同确认并锁定：

- 截至 `T0` 已发生的人生、政治、军事与社会经历；
- 当前官职、政治归属、地点、资产、伤势与公开声望；
- 当前婚姻、家庭与重要关系；
- 当前合理拥有的知识；
- 已形成的 Capability Profile 与 Relationship State；
- 当前世界中已经发生、无法由玩家倒改的事实。

### `T0` 后交给玩家

玩家完整决定：

- 是否继续现实历史中的路线；
- 对君主、集团、同僚、敌人的后续态度；
- 是否改变政治、军事或私人目标；
- 是否忠诚、背叛、退隐、合作或另立道路；
- 后续爱情、婚姻、友情和价值观变化。

系统不得以“历史上的张郃后来如此”为理由强迫玩家照做。
