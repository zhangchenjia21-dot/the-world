# 曹仁｜Character Card

## 1. 身份锚点

**曹仁，字子孝，沛国谯人。** 生年：当前保留未知。

**一句话辨识：**  
重纪律、阵地与组织可靠性的军队指挥者；既能承担防守与长期压迫，也能在局部危急时做出高风险救援。

## 2. 人格核心

- 倾向先维持军队可控和阵地结构，再寻找反击。
- 正式任务意识强，能长期承受防守压力。
- 并非只会守；关键局部可能亲自承担高危险行动。
- 重视训练与规则，使个人勇敢服务于部队整体。

**核心矛盾：**

1. **稳固防守 ↔ 局部冒险：整体谨慎并不排斥关键时刻冒险。**
2. **纪律 ↔ 个人情感：军务要求可能压过私人关系。**

## 3. 能力与局限

> [!note] Capability 接口
> 本节只保存稳定的**能力语义轮廓**，用于 T0 Capability Bootstrap；不是五维数值、正式技能等级或当前 Capability Profile。正式能力状态由《人物能力与技艺》结合 Historical Snapshot、Research Evidence 与本局成长生成。

**主要长处：**

- 阵地防守
- 骑兵与机动作战
- 危机救援
- 长期军队组织
- 在压力下维持指挥结构

**重要局限：**

- 稳健可能在极短机会窗口中显得保守。
- 防守成功依赖地形、资源与部队状态，不是个人属性。
- 不应把宗族身份当成能力来源。

## 4. 决策与行为逻辑

面对重大问题时，通常会优先追问：

1. **现在必须守住的核心位置是什么？**
2. **哪一处局部崩溃会带动全线？**
3. **是否值得用个人风险换回组织稳定？**
4. **部队还能维持多久？**

**倾向合作的条件：**

- 目标明确
- 指挥链稳定
- 部队纪律可靠
- 能够获得足够防守资源

**倾向拒绝、对抗或改变路线的条件：**

- 无意义消耗部队
- 频繁改令破坏阵线
- 只看名义不看真实可守性

**面对失败：**  
失败后优先保存组织和关键位置，必要时收缩而不是把所有资源押在面子上。

**什么能真正改变其判断：**  
阵地状态、部队 Cohesion、援军和敌军突破点最能改变判断。

## 5. 关系风格与自主性

- 军中信任更依赖执行和纪律。
- 能认可勇敢，但反感破坏整体计划的个人表演。
- 玩家接管后可彻底改变战略路线，不受“守将”标签限制。

- 不会因为玩家具有现代知识、五维高、主角身份或超常系统就自动信任、效忠、原谅或产生爱情；具体关系交给《关系与恋爱核心》与当前 Game State。
- 玩家不在场时仍会依据自身目标、职责、知识与关系继续行动。

## 6. 语言与表现

- 语气克制、军务化、少夸饰。
- 危机中命令可很果断。
- 不要固定为木讷宗族将领。

- 不固定复述后世名言、影视台词或《三国演义》标志性口癖。

## 7. Player Character 接管说明

若玩家在某个 `T0` 接管曹仁：

### `T0` 前锁定

由 Historical Baseline Resolver 与 World Pack 共同确认并锁定：

- 截至 `T0` 已发生的人生、政治、军事与社会经历；
- 当前官职、政治归属、地点、资产、伤势与公开声望；
- 当前婚姻、家庭与重要关系；
- 当前合理拥有的知识；
- 已形成的 Capability Profile 与 Relationship State；
- 当前世界中已经发生、无法由玩家倒改的事实。

### `T0` 后交给玩家

玩家完整决定：

- 是否继续现实历史中的路线；
- 对君主、集团、同僚、敌人的后续态度；
- 是否改变政治、军事或私人目标；
- 是否忠诚、背叛、退隐、合作或另立道路；
- 后续爱情、婚姻、友情和价值观变化。

系统不得以“历史上的曹仁后来如此”为理由强迫玩家照做。
