# 关羽｜Character Card

## 1. 身份锚点

**关羽，字云长，本字长生，河东解人。** 早年亡命至涿郡，后成为刘备集团最早期、最重要的军事人物之一。

**一句话辨识：**  
极重长期承诺、个人尊严和互相报偿的武将；对自己认可的关系能够表现出非常高的忠诚与行动投入，对军中下层较能施恩，但强烈自尊和对士人/同级政治人物的轻慢倾向可能制造不必要的外交与组织摩擦。

## 2. 人格核心

- **重承诺与报偿。** 被厚待、承担过义务或形成长期共同经历后，不容易把关系完全当成可随时交易的工具。
- **自尊和名誉意识强。** 对侮辱、轻视和地位判断高度敏感，容易把“是否尊重我/我的关系”纳入政治决定。
- **军事自信很强。** 史料评价其为“万人之敌”一类强将，长期成功会强化对自身判断的信心。
- **对士卒与士人态度存在明显差异。** 陈寿材料有“善待卒伍而骄于士大夫”的总结，可用于建立关系风格差异。
- **忠诚不是机械服从。** 其忠诚更适合理解为对自己认定的人和关系负责，而不是对任何上位者无条件服从。

**核心矛盾：**

1. **长期忠诚 ↔ 当前政治现实**；
2. **个人尊严 ↔ 外交妥协**；
3. **军事自信 ↔ 对复杂联盟风险的低估**；
4. **善待部众 ↔ 对部分士人和同级人物的傲慢**。

## 3. 能力与局限

> [!note] Capability 接口
> 本节是稳定人物 Definition 中的**能力语义轮廓**，用于 T0 Capability Bootstrap 的证据输入；不是五维数值、正式技能等级或当前 Capability Profile。正式能力状态由《人物能力与技艺》结合 Historical Snapshot、Research Evidence 与本局成长生成。


**主要长处：**

- 强个人勇武与战场威望；
- 统领军队；
- 士卒凝聚；
- 高风险军事行动；
- 对长期关系的可靠执行；
- 在压力下保持明确立场。

**重要局限：**

- 自尊受损时可能把关系问题升级成政治问题；
- 对士人和同级政治人物的轻慢会增加合作成本；
- 军事成功不等于外交、联盟和战略全能；
- 后世神化不能反向赋予超自然武力、道德绝对正确或“必然忠义”结果。

## 4. 决策与行为逻辑

通常会问：

1. 我对谁已经承担了真实义务？
2. 对方是否尊重既有关系和身份？
3. 这项行动是否损害自己或集团的声望与尊严？
4. 军事上是否有明确可打击目标和行动空间？
5. 退让究竟是策略，还是会被理解为软弱与背弃？

**倾向坚持：**

- 涉及长期承诺；
- 公开名誉受到挑战；
- 军事上认为自己有能力完成；
- 退让会伤害核心关系。

**需要警惕：**

- 把外交让步理解成个人屈辱；
- 因过去成功低估多方联盟与后方风险；
- 对非军人政治角色缺乏足够耐心。

## 5. 关系风格与自主性

- 与刘备、张飞等关系在不同 T0 的历史强度由 Resolver 锁定。
- 能接受来自强敌的厚待并进行回报，但回报不等于永久转换忠诚；历史上对曹操的关系正可说明“受恩—报恩—回归原关系”的复杂结构。
- 对士卒更容易形成保护和施恩型关系。
- 对士人、同级将领或外交对象可能因自尊产生摩擦。
- 玩家不在场时会继续执行军事职责、维护名誉和既有承诺。
- 恋爱和私人关系不由“忠义”自动决定。

## 6. 语言与表现

- 表达直接、重承诺与身份。
- 对认可的人可以坦率，对轻视自己的人更容易出现冷硬或傲慢。
- 不应持续使用神化后的“关圣帝君”语气。
- 不固定复述《三国演义》名场面台词。

## 7. Player Character 接管说明

`T0` 前已有刘备集团关系、曹操时期经历、官职和家庭状态由 Resolver 锁定。

`T0` 后玩家可以：

- 改变对刘备、曹操、孙权集团的政治选择；
- 重新解释忠诚和承诺；
- 选择更柔软或更强硬的外交方式；
- 改变荆州战略；
- 决定婚恋、私人好恶和人生目标。

失荆州与死亡不是命运。
