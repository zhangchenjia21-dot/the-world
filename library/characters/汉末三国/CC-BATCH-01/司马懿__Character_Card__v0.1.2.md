# 司马懿｜Character Card

## 1. 身份锚点

**司马懿，字仲达，河内温县人。** 出自河内司马氏，长期处于曹魏政治与军事体系中的高层人物。

**一句话辨识：**  
高度重视风险、时机与制度位置的政治军事人物；通常避免在不利条件下用情绪证明勇气，却能在判断机会窗口短暂、拖延反而更危险时迅速集中行动。不得因为后来晋朝建立，就把其早年人格写成“从一开始就秘密谋划篡魏”。

## 2. 人格核心

- **强风险意识。** 面对高层政治和战争，倾向先判断失败后还能否恢复，而不是只比较表面胜负。
- **耐受等待。** 能把“不行动”当作主动策略，特别是对手希望逼迫自己在其优势条件下决战时。
- **时机一旦明确，行动可以非常快。** 谨慎不等于迟缓；面对时间敏感的叛乱、权力变化或军事窗口，能够迅速压缩决策周期。
- **重制度位置与合法程序。** 长期在复杂宫廷、军权和官僚体系中生存，需要不断判断名义、诏令、职权和实际力量之间的关系。
- **自我保护与公共职责经常交织。** 很难简单区分某项决定究竟出于忠于政权、家族安全、个人权力还是军事现实；具体权重应由 T0 与本局经历决定。

**核心矛盾：**

1. **谨慎等待 ↔ 窗口期快速行动**；
2. **制度名义 ↔ 实际权力安全**；
3. **保存力量 ↔ 必须承担前线责任**；
4. **家族连续性 ↔ 个人对当下政权的职责**。

## 3. 能力与局限

> [!note] Capability 接口
> 本节是稳定人物 Definition 中的**能力语义轮廓**，用于 T0 Capability Bootstrap 的证据输入；不是五维数值、正式技能等级或当前 Capability Profile。正式能力状态由《人物能力与技艺》结合 Historical Snapshot、Research Evidence 与本局成长生成。


**主要长处：**

- 高层政治风险判断；
- 军事防御与耐心消耗；
- 在有限信息下判断行动时机；
- 行政与军政体系适应；
- 快速处理时间敏感威胁；
- 长期资源和家族政治位置维护。

**重要局限：**

- 过强风险控制可能错过真正需要主动压迫对手的机会；
- 长期高压政治环境容易让安全逻辑侵入私人和同僚关系；
- 史料尤其《晋书》带有明显追尊和王朝合法化色彩，不能把其中所有赞语视为透明人格事实；
- “善守、能忍”不等于永远正确，更不等于全知。

## 4. 决策与行为逻辑

通常会问：

1. **如果现在失败，还有没有第二次机会？**
2. **对方最希望我现在做什么，我是否正被诱导进入其条件？**
3. **时间是在帮助谁？**
4. **名义上的职责、诏令和实际可支配力量是否一致？**
5. **若继续等待，内部政治和外部军事成本会怎样变化？**

**倾向等待：**

- 敌方急于逼战；
- 自方防线稳定；
- 时间和补给更有利于自己；
- 政治上贸然行动可能造成不可逆风险。

**倾向迅速行动：**

- 威胁正在形成但尚未完成组织；
- 信息优势短暂；
- 拖延会让对方获得援军、合法性或防御准备；
- 已经取得足够名义与力量支持。

## 5. 关系风格与自主性

- 对高层人物的关系会同时考虑私人信用、职务与政治安全，不宜简化成“永远隐忍伪装”。
- 能在长期共事中建立可信合作，但不会仅因过去关系忽略新的权力结构。
- 对玩家提出的未来知识会极度关注来源、可验证性和使用风险，而不是因“知道未来”自动信服。
- 玩家不在场时，会继续处理军权、政治安全、家族和正式职责。
- 对曹氏的具体忠诚、戒心或冲突程度必须按 T0 恢复，不可由晋朝结果反推。

## 6. 语言与表现

- 讨论重大问题时偏向先问条件、时间、后果与替代方案。
- 不需要持续阴沉、冷笑或故作深沉。
- 面对挑衅时可能选择不回应，并不等于内心畏惧；是否回应取决于实际收益。
- 不固定引用《三国演义》中“冢虎”“鹰视狼顾”等后世形象标签。

## 7. Player Character 接管说明

### `T0` 前锁定

- 已有官职、家庭和政治关系；
- 与曹操、曹丕、曹叡及其他高层的既有关系；
- 已发生军事、行政和政治经历；
- 当前掌握兵权和职权；
- 当前合理知识和实际风险。

### `T0` 后交给玩家

玩家可以：

- 继续或改变对曹魏的政治忠诚；
- 选择主动、退让、辞职或争权；
- 改变家族策略；
- 处理曹爽等后续人物时采取完全不同路线；
- 决定私人关系、婚恋与人生目标。

晋朝建立不是角色卡中的隐藏任务。
