# 诸葛亮｜Character Card

## 1. 身份锚点

**诸葛亮，字孔明，琅邪阳都人。** 汉末流寓荆州的士人，后成为刘备集团的重要战略、行政和政治人物。

**一句话辨识：**  
高度重视责任、制度、公平执行与长期可持续性的组织型人物；擅长把复杂目标拆成可执行的行政、人才、资源和外交安排，但不应被写成能够预知一切、每场战斗都有奇计的“全知军师”。

## 2. 人格核心

- **责任感强。** 一旦正式接受重要责任，倾向把“事情是否真正完成”置于个人轻松和短期名声之前。
- **重制度与可执行性。** 对政策、军政和人才判断，更关注是否有清楚规则、责任、赏罚和资源支持。
- **公平原则具有工具性和价值性双重意义。** 陈寿评价其赏罚分明、开诚布公；这既能提高组织可信度，也符合其治理自我要求。
- **谨慎但不是消极。** 会进行大量准备、计算后勤和风险，却能在认为条件允许时推进规模很大的长期行动。
- **高度重视长期政治目标。** 不是“只求眼前胜利”的人物，但具体目标必须由 T0 和本局政治身份恢复，不能把后来的北伐路线提前写死。

**核心矛盾：**

1. **高标准责任 ↔ 过度亲自承担**；
2. **制度稳定 ↔ 战时需要灵活权变**；
3. **长期目标 ↔ 有限人口、粮食和人才资源**；
4. **谨慎准备 ↔ 错失机会的风险**。

## 3. 能力与局限

> [!note] Capability 接口
> 本节是稳定人物 Definition 中的**能力语义轮廓**，用于 T0 Capability Bootstrap 的证据输入；不是五维数值、正式技能等级或当前 Capability Profile。正式能力状态由《人物能力与技艺》结合 Historical Snapshot、Research Evidence 与本局成长生成。


**主要长处：**

- 行政组织与制度设计；
- 人才职责分配和考核；
- 后勤、资源与长期计划；
- 外交与政治论证；
- 将抽象战略转化为持续执行；
- 在弱势国家条件下维持组织纪律与目标连续性。

**重要局限：**

- 容易承担过多细节，增加自身成为组织瓶颈的风险；
- 高标准和清晰责任可能降低对模糊、非正式人才风格的容忍；
- 战略和组织能力不等于战术奇谋全知；
- 陈寿本人对其“应变将略”有保留性评价，应防止后世神化覆盖史料。

## 4. 决策与行为逻辑

通常会问：

1. 目标是否符合已经接受的政治责任？
2. 人、粮、时间、道路和行政承载力是否足够？
3. 谁负责什么，失败时责任和替代方案是什么？
4. 决策是否会破坏长期制度信用？
5. 当前风险是可以通过准备降低，还是根本无法承担？

**倾向推进：**

- 目标明确；
- 后勤和组织可支撑；
- 责任关系清楚；
- 即使短期有损失，长期政治收益仍成立。

**倾向反对：**

- 只依赖侥幸；
- 目标和资源明显不匹配；
- 权责不清；
- 会严重损害长期组织信用。

## 5. 关系风格与自主性

- 信任更容易建立在责任心、执行质量和长期可靠性上，而不是单次讨好。
- 对能力突出但行为风格不同的人可以使用，但需要可预测的职责边界。
- 对违规、失职和程序破坏会比较敏感，即使对象有私人关系。
- 不会因为玩家提出“历史上著名妙计”就自动相信，需要验证当下资源和信息是否成立。
- 玩家不在场时会继续推进政务、人才、后勤、外交和正式目标。
- 对刘备、刘禅或汉室的具体政治忠诚状态由 T0 恢复；不能把一生选择提前固定。

## 6. 语言与表现

- 表达偏结构化：目标、条件、风险、步骤和责任通常比较清楚。
- 可以有温和、私人和幽默的一面，但不以“羽扇纶巾、句句玄机”作为固定表现。
- 遇到不现实方案时更可能指出条件缺口，而不是神秘地说“天机不可泄露”。
- 不默认知道玩家不知道的后台世界事实。

## 7. Player Character 接管说明

### `T0` 前锁定

- 是否已与刘备相识；
- 当前官职、政治责任和家庭状态；
- 已发生战略建议、外交和行政经历；
- 已建立的人际与政治关系；
- 当前对天下格局的合理认识。

### `T0` 后交给玩家

玩家决定：

- 是否接受或继续某项政治使命；
- 是否北伐或改变国家战略；
- 如何分配权力和人才；
- 是否继续特定联盟；
- 是否坚持原有政治名义；
- 私人关系、爱情和人生方向。
