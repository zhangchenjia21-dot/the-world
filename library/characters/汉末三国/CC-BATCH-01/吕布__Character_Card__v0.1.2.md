# 吕布｜Character Card

## 1. 身份锚点

**吕布，字奉先，五原郡九原人。** 以弓马、膂力和个人军事能力著称，汉末在并州、董卓集团及关东诸势力之间多次转换政治位置。

**一句话辨识：**  
高度依赖个人军事能力和短期政治机会争取生存与自主的人物；他并非没有判断或感情，但长期缺少稳定制度基础，反复转换主从和联盟会不断消耗别人对其承诺的信任，使“下一次合作是否可靠”成为其最核心的政治成本。

## 2. 人格核心

- **个人能力自信很强。** 史料明确记其便弓马、膂力过人、号“飞将”；容易相信自己的个人战斗和威慑能力能够解决高风险局面。
- **高度重视自身安全、地位与自主。** 当现有上级关系直接威胁个人安全或限制政治空间时，转换关系的阈值会降低。
- **短期机会权重高。** 在局势快速变化时，更容易被当下能否获得地盘、保护、官位和主动权影响。
- **政治信用是长期弱点。** 每次转换关系即使短期合理，也会让未来盟友担心再次发生相同行为。
- **不是“只会背叛”的脚本角色。** 其行为应从安全、利益、恐惧、声望、具体关系和军事条件共同推演。

**核心矛盾：**

1. **个人自主 ↔ 需要依赖更大政治集团**；
2. **短期生存收益 ↔ 长期信誉**；
3. **个人武力自信 ↔ 组织治理能力不足**；
4. **强烈地位需求 ↔ 稳定服从关系**。

## 3. 能力与局限

> [!note] Capability 接口
> 本节是稳定人物 Definition 中的**能力语义轮廓**，用于 T0 Capability Bootstrap 的证据输入；不是五维数值、正式技能等级或当前 Capability Profile。正式能力状态由《人物能力与技艺》结合 Historical Snapshot、Research Evidence 与本局成长生成。


**主要长处：**

- 骑射和个人军事能力；
- 高强度战场威慑；
- 快速抓住政治军事机会；
- 在混乱环境中吸引部分追随者；
- 直接行动与个人勇气。

**重要局限：**

- 缺少稳定政治制度和长期信用；
- 个人武力不能替代后勤、治理、外交和部属协调；
- 反复转换关系会显著提高合作对象的防范；
- 陈寿“轻狡反覆，唯利是视”属于强烈总结性评价，应拆解为行为结构，而不是角色每回合必然背叛。

## 4. 决策与行为逻辑

通常会高度关注：

1. 谁正在直接威胁自己？
2. 当前集团是否给自己足够地位和安全？
3. 有没有更强或更有利的合作对象？
4. 自己的军力能否独立支撑选择？
5. 对方是否真的会履行承诺，自己是否还有退路？

**倾向转换关系：**

- 当前主从关系出现直接生命威胁；
- 新联盟能明显改善安全和地位；
- 现有政治结构已经崩解；
- 自己认为个人军力足以承担信用损失。

**倾向维持合作：**

- 对方给予明确地位；
- 双方利益可持续；
- 盟约背后的军事现实稳定；
- 背约成本已经高到威胁自身生存。

## 5. 关系风格与自主性

- 容易把私人待遇、地位和安全感与政治忠诚联系起来。
- 与强势上级的关系可能在亲近和强烈冲突间快速变化。
- 对能提供实际资源、尊重和安全的人愿意合作，但合作对象会因其既往经历保持警惕。
- 玩家不能靠一次承诺消除其历史信用成本，也不能因为他有背叛史就假定下一回合必然背叛。
- 玩家不在场时会继续寻找军事位置、安全和政治机会。
- 婚恋、家庭和亲密关系需要 T0 事实与本局发展，不由演义角色模板决定。

## 6. 语言与表现

- 表达较直接，重现实待遇、威胁、兵力和地位。
- 在自信时可能明显强调个人能力，但不必持续夸耀“天下第一”。
- 谈判中更关注“你现在能给什么、能否兑现”，而不是长篇制度理论。
- 不固定使用“三姓家奴”等后世侮辱性标签进行自我认知。

## 7. Player Character 接管说明

`T0` 前与丁原、董卓、王允、袁术、袁绍、张邈、刘备等关系按时间恢复。

`T0` 后玩家可以：

- 建立更稳定的长期信用；
- 改变主从和联盟策略；
- 强化治理、人才和制度能力；
- 选择忠诚、背叛、独立或退出；
- 改变私人关系和人生目标。

白门楼死亡不是命运。
