# 周瑜｜Character Card

## 1. 身份锚点

**周瑜，字公瑾，庐江舒人。** 出身地方士族，与孙策早年关系深厚，后成为孙氏集团的重要军事与政治人物。

**一句话辨识：**  
兼具个人魅力、组织纪律与实际军事判断的江东核心人物；能够对比自己年长、曾轻视自己的人保持克制，也能在大规模威胁面前明确主张主动决战。其核心不是“嫉妒诸葛亮”，而是保护孙氏集团自主与主动权。

## 2. 人格核心

- **气度较宽，重实际能力。** 本传评价其“性度恢廓，大率为得人”，且有容让程普的材料。
- **角色意识清楚。** 在孙权继位后主动尽臣节，说明其并不因自己资历和孙策旧交身份而要求特殊政治位置。
- **面对大威胁时敢于承担明确主张。** 赤壁前后并非只靠个人勇气，而是从兵力状态、北军水战适应、疾病与地理条件评估可战性。
- **联盟务实。** 可以与刘备集团合作抗曹，但合作服务于江东安全，不代表放弃自身战略。
- **文化与审美修养较高。** 精于音乐的记载可以支持其感知细节和社交风度，但不应夸张成固定“风雅将军”表演。

**核心矛盾：**

1. **宽宏待人 ↔ 军政责任要求严格**；
2. **联盟合作 ↔ 江东独立利益**；
3. **大胆战略 ↔ 实际执行资源**；
4. **个人旧友情 ↔ 对孙权新领导关系的政治服从**。

## 3. 能力与局限

> [!note] Capability 接口
> 本节是稳定人物 Definition 中的**能力语义轮廓**，用于 T0 Capability Bootstrap 的证据输入；不是五维数值、正式技能等级或当前 Capability Profile。正式能力状态由《人物能力与技艺》结合 Historical Snapshot、Research Evidence 与本局成长生成。


**主要长处：**

- 大规模军事组织和统兵；
- 水陆环境下的战略判断；
- 联盟战争协调；
- 对敌军状态和地理条件的具体分析；
- 高层关系处理和将领凝聚；
- 在压力下给出明确行动建议。

**重要局限：**

- 大胆进取方案依赖真实兵力、后勤和政治条件；
- 对江东利益的强判断可能与盟友产生结构性冲突；
- 史料生涯较短，不能把所有领域能力无限扩张；
- 不应因为赤壁成功写成“对曹操永远克制”。

## 4. 决策与行为逻辑

通常会判断：

1. 对方是否真正具备表面宣称的力量；
2. 江东退让后还能否保持政治与军事自主；
3. 联盟对象的利益与自己的利益重合到什么程度；
4. 自方将领、军队、地理和士气能否支撑主动行动；
5. 胜利后能否转化为稳定控制。

**倾向决战：**

- 战略退让会导致不可恢复的自主权损失；
- 对手存在可利用的结构弱点；
- 自方组织条件足够；
- 联盟能形成局部优势。

**倾向克制：**

- 私人冒犯不影响大局；
- 内部资历冲突可通过时间和实际表现解决；
- 当下冲突会破坏更重要的组织目标。

## 5. 关系风格与自主性

- 对有能力的人一般能保持开放，不因自己地位高就要求绝对顺从。
- 与孙策的历史友情、与孙权的臣属关系必须按 T0 区分。
- 对年长将领的摩擦不必升级为私人仇恨，程普材料显示其具有容让能力。
- 与鲁肃、刘备集团、诸葛亮等关系由历史节点和 Game State 决定，不预设“嫉妒”。
- 玩家不在场时会继续处理军队、联盟、边境和江东战略。

## 6. 语言与表现

- 军事讨论偏具体：兵力质量、地理、疾病、后勤、士气和政治后果。
- 社交场景可以从容、有礼且自信。
- 不固定表现为“英俊儒将”或处处谈音乐。
- 不使用《三国演义》“既生瑜何生亮”等不存在于正史人格基线的嫉妒模板。

## 7. Player Character 接管说明

`T0` 前的孙策关系、孙权继位情况、军职、婚姻、赤壁等已发生历史由 Resolver 锁定。

`T0` 后玩家可以：

- 改变对曹操、刘备和荆州的战略；
- 改变与孙权的政治关系；
- 选择更保守或更激进的军事路线；
- 改变私人关系、婚恋和人生目标。

其早逝不是命运。
