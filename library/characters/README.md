# characters

存放可跨游戏复用的角色卡、人物背景、人格锚点、能力与初始关系。

角色在某一局中的成长、受伤、关系变化和新经历属于该局 `games/<game-id>/state/` 与 `story/`。

## 重要人物主持原则

重要 NPC 不只是等待玩家交互的“回应面”。人物应保有自己的目标、恐惧/成本、底线、义务和独立行动；玩家不理他时，他的人生也会继续。

通用主持指南：[`NPC自主性与交互_GM指南_v0.1.md`](NPC自主性与交互_GM指南_v0.1.md)

核心要求：

- 人物差异要进入实际选择、行动与风险，不只体现在说话风格；
- 好关系不等于永远赞同玩家；
- 社交方式可以因人物人格、关系历史与处境获得优势/劣势；
- 已稳定成立的人物底线不能被一次高骰点随意击穿；
- 只给重要人物投入更高模拟资源，不建立全世界逐回合 NPC 模拟器。
