# 1. 世界身份

## 1.1 世界名称

**汉末三国：天下未定**

## 1.2 一句话定位

以东汉末年至三国归晋为历史舞台、以正史为主要基线的开放历史沙盒：玩家可以从不同时间节点、以任何时代内合理身份进入世界；进入之前的历史构成既成事实，进入之后的未来必须重新由人物、资源、环境与玩家行动共同产生。

## 1.3 题材标签

- 中国历史；
- 东汉末年；
- 三国；
- 开放历史；
- 历史沙盒；
- 社会生活；
- 士人政治；
- 军阀割据；
- 王朝鼎革；
- 长期角色扮演；
- 可选穿越；
- 可选恋爱；
- 可组合机制资产。

## 1.4 世界尺度

**大型历史开放世界。**

世界覆盖约一个世纪，但不要求任何一局同时高精度运行全部地区、全部人物或全部事件。

Runtime 应根据玩家当前时间、Region、身份、关系和已激活内容，只实例化当前真正需要的部分；远方地区可以保持较粗的世界事实与趋势表达。

## 1.5 默认体验基调

- 史诗，但不是“玩家天然是天命主角”；
- 写实，但不是机械历史模拟器；
- 政治复杂，但不预设所有人都犬儒；
- 战乱残酷，但不以猎奇作为主要体验；
- 历史有惯性，但没有历史修正力；
- 名人重要，但普通人也能拥有完整人生；
- 允许宏大争霸，也允许经商、仕宦、从军、行医、求学、迁徙、经营家族或单纯求生。

# 2. 玩家可见世界摘要

这是一个从东汉末年走向三国、又可能走向完全不同未来的中国历史世界。

你可以从黄巾大乱之后的汉末乱世开始，也可以从官渡、赤壁、三国鼎立、魏末权力更替乃至天下即将归晋的时代进入。

你可以扮演一名史书留名的人，也可以只是州郡小吏、乡里士人、军中卒伍、商旅、医者、工匠、豪族子弟、农户、流民，或另行创建符合时代条件的身份。

如果你选择扮演历史人物，那么在你接管这个人物以前，他已经发生的经历仍然属于过去；从接管之刻起，他的未来选择归你。

如果你选择一个无名人物，那么曹操、刘备、孙权、诸葛亮、周瑜、司马懿等名人不会因为你是玩家就自动认识你、信任你或等待你加入。他们存在于自己的社会网络、政治责任和人生轨迹中。

历史会提供强大的惯性，却不会替世界预写下一页。

> **过去可以被继承，未来必须重新发生。**

# 3. 世界最高语义原则

## 3.1 历史基线不是剧情脚本

玩家所选开局时间以前已经发生的历史，原则上属于本局的世界基线。

玩家进入以后：

- 尚未发生的原历史事件不再具有“必然发生”权威；
- 原历史只能作为一种参考轨迹；
- 若事件前提依然成立，它可能自然发生；
- 若事件前提已经被玩家或世界改变，它必须允许改变、延后、提前、转化或彻底消失；
- 不允许用“历史修正力”强迫人物重新走回史书轨迹。

## 3.2 先有世界因果，再有历史结果

世界不能先决定“赤壁必须发生”“关羽必须败亡”“蜀汉必须灭亡”“司马氏必须代魏”，再临时寻找理由。

任何重大历史变化必须来自当前世界中已经存在的：

- 人物选择；
- 势力条件；
- 地理与交通；
- 资源与时间；
- 社会网络；
- 战争或灾害；
- 合法玩家行动；
- Runtime 正式裁定。

## 3.3 历史人物仍是自主角色

世界包允许历史人物存在，却不拥有他们的完整人格 Definition。

完整的人物身份、人格、价值观、长期目标、私密资料和人物专属生涯，应由对应 Character Card 持有。

World Pack 只在世界事件与时间锚点中引用人物名字与其已经发生的公共历史角色，不复制第二份完整人物事实。

## 3.4 玩家不是自动的时代中心

玩家可以改变历史，但必须获得实际接触世界中心的路径。

- 无名军士不会自动进入最高军议；
- 普通商人不会因为玩家身份自动成为诸侯座上宾；
- 乡里百姓不会天然知道朝廷机密；
- 史书名人不会自动把玩家当作可信盟友。

任何社会跃迁都需要符合世界内身份、关系、机会和因果。

## 3.5 无预设唯一结局

可能出现但不保证出现：

- 曹魏；
- 蜀汉；
- 孙吴；
- 司马氏掌权；
- 西晋统一；
- 汉室复兴；
- 新的第四或第五个长期政权；
- 玩家建立的新势力；
- 天下长期分裂；
- 与现实完全不同的统一者。

# 4. 历史资料与创作来源规则

## 4.1 来源层级

后续扩写本 World Pack 时，内容必须标明其语义来源层级。

### A｜来源支持的史实

优先依据：

- 《后汉书》：东汉末朝廷、人物与事件；
- 《三国志》：魏、蜀、吴人物与政权事实；
- 裴松之注所保存的异说与补充材料；
- 《资治通鉴》：年代关系与事件顺序的交叉核查。

### B｜史料争议

若不同史料存在冲突：

- 不静默拼成一个不存在的“统一事实”；
- 标记争议；
- 若游戏必须选择其中一种版本，记录为 World Pack 明确创作裁定；
- 若不影响可玩性，可以保留未知。

### C｜合理推断

用于连接已知事实之间的低风险空白。

必须允许未来被更高质量资料推翻。

### D｜文学传统

《三国演义》、戏曲、评话、民间传说等可以作为：

- 文化影响；
- 民间传闻；
- 可选传奇化参考；
- Creator 辅助灵感。

默认不自动升级为历史世界事实。

### E｜原创补全

史料真实留白处允许原创，但必须：

- 不破坏已知时间；
- 不冲突于已知人物经历；
- 符合地理、制度与社会身份；
- 不因“剧情需要”制造唯一未来。

### F｜游戏实例产生的新历史

玩家开局以后产生的一切新历史属于 Game State / Event。

它不能回写原始 World Pack 作为“历史上本来就如此”。

## 4.2 年代与历法说明

本稿为了人工阅读，主要以公元纪年表示推荐锚点。

正式 Runtime 将来若支持汉末、魏、蜀、吴、晋各政权年号与历法显示，应把：

- 内部权威时间；
- 角色所处政权使用的纪年；
- 玩家可见时间；

分开处理。

当前 Markdown 不尝试冻结具体 Calendar Schema。

## 4.3 精确日期谨慎原则

本世界横跨不同政权、不同年号和传统历法。对精确到月、日的历史事件：

- 未经专项核查不随意补造现代公历日期；
- 当前世界包优先保存年、时期、先后关系；
- 创建具体时间快照时再进行专项验证。

# 5. 历史覆盖范围

## 5.1 总体窗口

推荐核心历史窗口：

> **公元 184 年左右 — 公元 280 年**

这里的“汉末三国”采用游戏体验上的广义范围。

狭义“三国”通常从汉魏鼎革后的 220 年开始，但若只从 220 年开始，将失去黄巾、董卓、群雄割据、官渡与赤壁等决定三国格局形成的重要前史。

## 5.2 历史阶段划分

### 阶段 I｜汉廷失序与地方军事化（约 184—189）

- 东汉仍是名义上的统一王朝；
- 黄巾等大规模动乱使地方军事力量和州郡权力迅速上升；
- 士人、宦官、外戚、地方官和地方武装之间的政治矛盾加剧；
- 后来许多三国人物此时仍处于人生早期阶段。

### 阶段 II｜董卓与群雄割据（约 189—196）

- 中央朝廷权威遭到严重破坏；
- 洛阳、长安及皇帝成为政治合法性争夺的核心；
- 地方诸侯、州牧、太守、豪族与私人军队逐渐形成彼此竞争的权力中心；
- “天下”尚不存在稳定的魏、蜀、吴三方结构。

### 阶段 III｜北方争霸与南方重组（约 196—208）

- 曹操在迎奉汉献帝后形成新的北方政治中心；
- 袁绍与曹操竞争北方主导权；
- 荆州、江东、益州等区域保有独立政治空间；
- 200 年官渡及其后续改变北方格局；
- 208 年荆州变化与赤壁前后的冲突阻止北方力量迅速统一长江以南。

### 阶段 IV｜三方政权形成（约 208—229）

- 曹氏控制北方；
- 孙氏稳定江东；
- 刘备集团取得荆益立足点；
- 220 年汉魏鼎革；
- 221 年刘备称帝；
- 229 年孙权称帝；
- 至此现实历史中的三国政权格局正式形成。

### 阶段 V｜三国长期对峙（约 229—249）

- 魏、蜀汉、吴分别拥有相对稳定的国家结构；
- 三国之间持续存在边境冲突、外交与战争；
- 各国内部的继承、官僚、地方集团和君臣关系逐渐成为决定未来的重要因素。

### 阶段 VI｜魏末权力转移与三国终局（约 249—280）

- 魏国内部权力逐渐转移到司马氏；
- 263 年蜀汉灭亡；
- 魏晋禅代后，晋取得北方与原蜀地资源；
- 280 年晋灭吴，现实历史中的三国分裂结束。

> [!warning] 开放历史提醒
> 上述阶段只描述**现实历史基线**。
> 玩家若在更早节点进入，此后阶段不再具有强制发生权。

# 6. 推荐开局时间锚点

> [!note] 锚点用途
> 推荐锚点不是固定剧本章节，而是方便 Creator / Game Creation 建立历史快照的世界入口。
>
> 每个锚点只说明“此刻世界已经是什么样”，不规定玩家接下来必须经历什么。

## 6.1 184｜黄巾大乱

**定位：** 最早期大规模改写历史入口。

### 已经成立的世界事实

- 东汉仍然存在；
- 汉灵帝在位；
- 中平元年发生大规模黄巾起事；
- 朝廷与地方开始大规模调兵应对动乱；
- 地方军事力量、豪族与州郡社会的自主性显著上升。

### 此刻尚未被锁定为未来事实

- 董卓是否控制朝廷；
- 曹操、刘备、孙氏集团是否形成现实历史中的权力规模；
- 魏、蜀、吴是否出现。

### 特别适合

- 无名小卒；
- 地方士人；
- 军士；
- 豪族子弟；
- 流民；
- 医者；
- 商旅；
- 早期历史人物接管。

---

## 6.2 189｜洛阳巨变

**定位：** 中央政治崩解与群雄时代的入口。

### 已经成立的世界事实

- 汉灵帝已死；
- 外戚、宦官与朝廷武装之间发生激烈权力斗争；
- 董卓进入中央政治并控制皇帝与朝廷；
- 帝都秩序与汉廷权威遭到重大破坏。

### 开放局面

- 各地政治人物如何回应中央危机尚有巨大空间；
- 关东诸侯的联合、分裂与未来道路并非强制；
- 洛阳与长安的命运可以被改变。

### 特别适合

- 朝廷官僚；
- 京师士人；
- 武官；
- 地方诸侯集团成员；
- 游侠、商旅、军士；
- 想深度介入汉室存亡的玩家。

---

## 6.3 196｜天子至许

**定位：** 汉廷名义与军阀实力重新结合的政治入口。

### 已经成立的世界事实

- 汉献帝已经经历长安政局与东归；
- 曹操迎奉献帝并将朝廷安置于许；
- 天下已存在多个相对独立的军事政治中心；
- 袁绍、曹操、吕布、刘备、孙氏、刘表等力量仍在不同地区活动。

### 开放局面

- 谁能成为北方主导力量并未由世界包预定；
- 汉帝国名义与地方实际权力之间的关系仍可能走向不同未来。

### 特别适合

- 士人仕途；
- 朝廷政治；
- 北方军阀竞争；
- 外交与人才流动；
- 商旅与地方经营。

---

## 6.4 200｜官渡前夕

**定位：** 北方大战与人才选择的入口。

### 已经成立的世界事实

- 袁绍与曹操已经成为北方最重要的竞争力量之一；
- 两方拥有不同的政治基础、控制区域与人才网络；
- 北方控制权仍未最后决定。

### 开放局面

- 官渡之战是否按现实方式发生；
- 谁胜谁负；
- 河北与中原未来如何整合；
- 其他地区力量是否介入；

全部必须由新世界因果重新产生。

### 特别适合

- 谋士；
- 将领；
- 州郡官吏；
- 豪族；
- 军需商旅；
- 袁曹双方历史人物。

---

## 6.5 208｜赤壁前夕

**定位：** 最经典的南北格局转折入口。

### 已经成立的世界事实

- 曹操已在北方取得显著优势；
- 荆州政治格局发生重大变化；
- 刘备集团处于重新寻找立足点的阶段；
- 孙权控制江东并面对来自北方的巨大压力；
- 长江中游成为决定未来格局的重要区域。

### 开放局面

- 孙刘是否结盟；

## 6.13 自定义年份

允许玩家在历史窗口内选择其他年份。

- 当年存在的政权；
- 君主与主要政治中心；
- 已发生世界级事件；
- 地名是否已改称；
- 相关人物是否已经出生、死亡或退出政治舞台；
- 相关人物卡是否适用于该时点；
- 哪些现实历史事件仍属于未来而不能泄漏为世界事实。

# 7. 历史空间结构

## 7.1 空间模型

本世界使用项目统一空间语义：

```text
Region
→ Place
→ Scene
```

World Pack 负责提供历史空间内容；Runtime 负责正式位置状态。

## 7.2 Region 设计原则

汉末三国的行政区划、政权疆界和地方称谓随年代变化明显。

因此 World Pack 的 Region 首先是**稳定的游戏空间导航层**，不是声称“一个世纪里行政区永远不变”。

Region 可以参考州、地理区、流域和长期政治区域组织，但具体行政归属必须以时间快照为准。

## 7.3 推荐高层 Region

### 两京与河南核心区

代表性空间：

- 洛阳；
- 河南尹周边；
- 许；
- 河内及周边交通区。

特点：

- 汉廷与曹魏政治核心的重要舞台；
- 黄河与中原交通节点密集；
- 不同时期政治中心变化明显。

### 关中

代表性空间：

- 长安；
- 潼关方向；
- 京兆及关中平原。

特点：

- 帝都与军事战略价值并存；
- 连接中原、凉州、汉中的重要区域。

### 河北

代表性空间：

- 邺；
- 冀州腹地；
- 幽州方向；
- 黄河北部诸郡。

特点：

- 袁绍集团及其后北方政治的重要基础；
- 人口、农业与军政资源在历史上具有重要地位。

### 并州与北部边地

特点：

- 中原政权、地方军政势力与北方边地社会长期交汇；
- 骑兵、边防、迁徙和族群互动更常见。

### 凉州与西北

代表性方向：

- 陇右；
- 河西方向；
- 长安以西交通带。

特点：

- 地方军事集团、羌胡等多族群社会、中央政权与边地秩序长期互动；
- 不能把整个西北写成单一“蛮荒势力”。

### 兖豫中原

代表性空间：

- 兖州、豫州相关地区；
- 官渡周边；
- 颍川等士人网络活跃地区。

特点：

- 汉末北方政治、人才与战争的重要腹地；
- 多条主要交通路线交汇。

### 徐淮

代表性空间：

- 下邳；
- 淮河沿线；
- 寿春方向。

特点：

- 北方、中原与江东之间的重要过渡区；
- 多次成为军阀与三国边境竞争区域。

### 荆州与长江中游

代表性空间：

- 襄阳；
- 江陵；
- 江夏；
- 赤壁—乌林相关水域。

特点：

- 南北水陆交通枢纽；
- 汉末至三国形成过程中最关键的争夺区域之一；
- 地理、宗族和地方士人网络都非常重要。

### 益州、巴蜀与汉中

代表性空间：

- 成都；
- 汉中；
- 巴地；
- 蜀地主要山地通道。

特点：

- 四川盆地拥有强烈地理独立性；
- 北出汉中的道路与山地通道决定对外联系；
- 蜀汉历史核心区域。

### 江东与长江下游

代表性空间：

- 吴郡；
- 会稽；
- 丹阳；
- 建业／秣陵相关地区；
- 长江下游港口与水网。

特点：

- 孙氏政权的核心区域；
- 河流、水网与地方大族对政治和社会结构影响显著；
- 地名、政治中心与都城称谓需要随年份处理。

### 交州与岭南

特点：

- 距离中原政治中心遥远；
- 地方行政、交通和区域社会具有独立节奏；
- 不能把其写成“没有历史的边缘地图”。

### 辽东与东北边地

特点：

- 在部分汉末三国时间节点具有独立的地方政治意义；
- 与幽州、朝鲜半岛北部及东北亚交通存在联系；
- 是否高精度加载应视具体开局而定。

## 7.4 Place 级重要历史节点候选

World Pack 可逐步扩充以下 Place，但本 v0.2 不建立穷尽式城市数据库：

- 洛阳；
- 长安；
- 许；
- 邺；
- 官渡；
- 下邳；
- 寿春；
- 合肥；
- 襄阳；
- 江陵；
- 赤壁／乌林相关战区；
- 成都；
- 汉中；
- 建业／秣陵；
- 武昌相关区域。

## 7.5 地名时间敏感性

同一地点在不同年代可能：

- 改名；
- 改变行政隶属；
- 改变都城地位；
- 改变军事重要性；
- 被不同政权控制。

因此不得把 229 年的地名与政治含义无条件复制到 189 年。

## 7.6 Scene 粒度

Place 内可按实际互动创建 Scene，例如：

```text
洛阳
├─ 宫城相关区域
├─ 官署
├─ 市肆
├─ 城门与道路
└─ 私宅／馆舍
```

或：

```text
军营
├─ 中军帐
├─ 营门
├─ 粮秣区
├─ 伤兵区
└─ 外围警戒地
```

Scene 是互动空间，不是固定地图网格。

# 8. 社会结构与身份空间

## 8.1 皇室、宗室与朝廷

东汉末年世界仍高度重视：

- 皇帝名义；
- 宗室身份；
- 朝廷诏命；
- 礼制与官号；
- “谁有资格代表天下秩序”的政治语言。

即使中央实际控制力下降，汉室名义也不能被写成毫无意义的装饰。

## 8.2 士人与官僚

士人世界由多种因素共同构成：

- 经学与教育；
- 家世；
- 乡里名望；
- 察举、征辟等仕进传统；
- 私人师友关系；
- 地方与中央官僚网络。

进入曹魏及后续时代后，选官方式与门第政治会继续变化。

具体“如何获得官职”的运行规则归《汉末三国：政争与势力》Expansion，而不是本 World Pack。

## 8.3 豪族、宗族与地方社会

地方大姓、豪族与宗族可以拥有：

- 土地；
- 声望；
- 门生故吏；
- 依附人口；
- 地方保护能力；
- 与官府或军政集团的关系。

但不同地区、不同家族差异很大，不应把“豪族”写成统一职业或同一政治立场。

## 8.4 军事人物

可能包括：

- 将领；
- 军吏；
- 部曲；
- 普通士卒；
- 地方武装成员；
- 护卫；
- 边地军人。

“武将”不是超自然职业。

个人勇武可以重要，但仍处于军队、社会身份和世界因果之中。

## 8.5 农户、流民与依附人口

长期战乱会使大量普通人的生活受到：

- 征发；
- 土地破坏；
- 粮食短缺；
- 疫病；
- 迁徙；
- 治安变化；
- 政权更替；

影响。

普通人的人生不只是“大人物战争的背景板”。

## 8.6 商贾与工匠

合理身份包括：

- 行商；
- 坐贾；
- 船商；
- 手工业者；
- 铁工、木工等技术人员；
- 与军需、运输、城市市场相关的人物。

世界承认商业与手工业的重要性，但具体经济数值与经营循环归经济类 Expansion。

## 8.7 医者、方士与宗教人物

可存在：

- 医者；
- 方士；
- 占卜与术数实践者；
- 道教相关宗教人物；
- 佛教僧侣与传播者；
- 地方祭祀相关人物。

他们的存在不自动证明超自然力量真实。

## 8.8 女性角色

女性历史人物与原创女性角色必须被视为真实社会行动者，而不是只作为婚姻奖励。

她们可能受到家庭、身份、礼法与政治环境的限制，也可能通过：

- 家族；
- 财产；
- 婚姻；
- 教育；
- 宫廷；
- 地方社会；
- 私人网络；

产生现实影响。

具体人物经历归 Character Card。

## 8.9 边地与多族群社会

汉末三国世界不只有“中原汉人 vs 外族”两种简单身份。

不同时间、不同地区可出现：

- 羌；
- 乌桓；
- 匈奴诸部；
- 山越；
- 西南与岭南不同地方群体；
- 其他边地社群。

不得把这些群体统一写成野蛮、敌对或同一种文化。

具体身份与政治关系应按 Region、时代与人物资料分别处理。

# 9. 制度与政治文化背景

> [!important] 边界
> 本节只描述时代制度背景。
> “官职如何授予”“合法性怎样计算”“外交怎样 Resolution”不属于 World Pack。

## 9.1 汉制余绪

东汉末年即使中央衰弱，州、郡、县、官职、诏令、礼制、印绶、察举、征辟等制度语言仍构成政治世界的基本语法。

地方军阀往往并非简单宣布“我拥有一块地”，而会争夺：

- 官号；
- 朝廷承认；
- 州郡名义；
- 皇帝与诏命；
- 士人支持；
- 家族声望；
- 军事事实控制。

## 9.2 州郡县不是永久固定地图

汉末至三国期间：

- 州郡设置会变化；
- 政权会拆分、改置行政区；
- 同一地区可能在不同政权体系中使用不同建制；
- 军事控制与名义行政隶属可能不完全一致。

因此精确行政地图必须绑定时间锚点。

## 9.3 官职是身份事实，不是 RPG 职业

官职意味着：

- 法定或名义职责；
- 政治地位；
- 社会礼序；
- 可能拥有的行政或军事权力；
- 与某政权的正式关系。

同一个官号在不同时期和实际局势中的权力可能不同。

## 9.4 正统与王朝名义

现实历史中：

- 曹魏通过汉帝禅让建立自身合法性叙事；
- 蜀汉强调延续汉室；
- 吴最终建立独立帝号；
- 晋又通过魏晋禅代建立新王朝。

本 World Pack 保存这些作为对应时间节点前已经发生的历史事实。

玩家更早进入后，后续禅代与称帝都不再是固定未来。

# 10. 经济与物质生活背景

> [!important] 边界
> 本节定义“这个时代的经济世界大致如何存在”，不定义数值资源与经济循环。

## 10.1 农业基础

粮食生产、土地与人口是国家、军队与普通社会生活的基础。

长期战争会直接影响：

- 耕作；
- 人口分布；
- 城乡安全；
- 运输；
- 市场；
- 地方政权的持续能力。

## 10.2 货币与实物交换

不同时间和地区的货币状况并不完全一致。

战乱环境下，粮食、布帛及其他实物可能具有重要交换价值。

World Pack 不冻结统一“金币”货币，更不会把整个世界抽象成固定金币经济。

## 10.3 城市与市场

重要城市和交通节点可能拥有：

- 市；
- 旅舍；
- 仓储；
- 工匠区；
- 官署；
- 河港；
- 城门税与检查；
- 地方商人网络。

具体 Place 应按年份与地区逐步补充。

## 10.4 战乱与迁徙

汉末战争造成大范围人口流动。

在游戏中，“来自异乡”“流亡”“随军迁徙”“投靠宗族或豪强”“南迁”等都应是合理的人生背景。

但人口变化的动态计算属于未来机制资产或 Runtime，而非本 World Pack。

# 11. 军事世界背景

> [!important] 边界
> 本节只定义军事现实的世界常识。
> 兵力、士气、补给、战役与 Resolution 全部移交《汉末三国：军略与战争》Expansion。

## 11.1 军队不是名将卡牌集合

军队需要：

- 人；
- 组织；
- 将领；
- 武器；
- 粮秣；
- 运输；
- 时间；
- 地形适应；
- 后方支持。

个人勇武不应无视这些条件。

## 11.2 地理差异影响军事现实

北方平原、关中通道、汉中山路、长江水网、巴蜀盆地、江东河网等地理差异，会自然影响：

- 行军；
- 通信；
- 船运；
- 骑兵使用；
- 防守；
- 远征成本。

本 World Pack 只提供地理背景，不计算战斗结果。

## 11.3 军事身份可以是长期人生

玩家可以长期扮演：

- 普通士卒；
- 军吏；
- 护卫；
- 部曲成员；
- 将领；
- 军中技术人员；
- 后勤与运输相关人物。

不要求所有军旅角色最终成为诸侯。

# 12. 技术、交通与通信边界

## 12.1 技术总基调

本世界默认是东汉末年至魏晋之际的前工业社会。

### 允许出现

- 铁制农具与兵器；
- 弓弩；
- 甲胄；
- 攻守城器械；
- 马匹与车辆；
- 大规模河运与船舶；
- 木工、冶金、纺织、陶器等成熟手工业；
- 纸张与其他传统书写材料；
- 中医药与当时医学实践。

### 默认不允许作为时代普通技术

- 火药枪炮；
- 蒸汽机；
- 电力；
- 现代工业制造；
- 现代通信；
- 抗生素与现代医疗体系；
- 现代意义的大规模印刷出版；
- 现代金融系统。

穿越者知道现代知识不等于拥有现代工业基础。

## 12.2 交通

常见交通方式包括：

- 徒步；
- 马；
- 车；
- 河船与江船；
- 地方道路与驿传体系。

旅行速度应受：

- 距离；
- 道路；
- 地形；
- 河流；
- 季节；
- 战乱；
- 身份与关津；

影响。

具体耗时由 Runtime 判断，不由 World Pack 写死统一公式。

## 12.3 通信

远距离消息主要依赖：

- 使者；
- 驿传；
- 私人信使；
- 军事传令；
- 商旅与口耳传播。

不存在即时跨区域通信。

因此“远方已经发生”与“玩家角色已经知道”必须严格分离。

# 13. 文化、信仰与超自然边界

## 13.1 文化背景

世界允许出现：

- 儒家经典与士人教育；
- 孝、忠、名节、家族与礼法等社会价值；
- 汉末清议与人物品评；
- 文学、诗赋与建安文化；
- 地方习俗；
- 祭祀与祖先观念。

不同人物可以接受、拒绝或重新解释这些价值，不把时代文化写成所有人完全一致的思想。

## 13.2 宗教与信仰

允许存在：

- 太平道等汉末宗教运动；
- 天师道等早期道教相关传统；
- 佛教在汉末魏晋的传播；
- 地方神祇与祭祀；
- 占卜、谶纬、梦兆、方术、术数等文化实践。

## 13.3 默认超自然规则

本 World Pack 默认：

> **不确认客观可验证的魔法、仙术或神迹作为普通世界规律。**

人物可以相信超自然，也可以怀疑。

占卜、梦境、预言与方术可以真实影响人的行为，却不能在没有额外资产支持时自动获得超自然权威。

## 13.4 穿越与“系统”

世界包**兼容**穿越者身份，但不负责解释或运行穿越系统。

- “来自现代”属于玩家角色 Definition；
- “拥有系统”属于 `[[穿越与系统_Expansion_Pack_v0.2]]` Expansion；
- 未启用该 Expansion 时，仍可以存在“穿越但无系统”的玩家角色；
- 系统不得因此把整个汉末世界改写成公开超自然社会。

# 14. 信息边界与历史知识

## 14.1 三层信息必须分离

```text
世界真实
≠
角色知识
≠
玩家可见叙事
```

## 14.2 时间越早，未来知识越不是世界事实

例如 184 年开局：

- “曹魏将在 220 年建立”不是世界事实；
- “刘备会建立蜀汉”不是世界事实；
- “孙权会在 229 年称帝”不是世界事实；
- “晋将在 280 年统一”更不是世界事实。

这些只是现实世界中玩家可能知道的历史。

## 14.3 本地角色知识

本地人物只应知道符合以下条件的信息：

- 所处年份；
- 身份；
- 教育；
- Region；
- 社会关系；
- 是否亲历；
- 消息是否已经传播到当地。

## 14.4 穿越者历史知识

若玩家 Character Definition 规定其来自现代，可以拥有与人物背景匹配的历史知识，例如：

- 只听过三国名人；
- 读过《三国演义》；
- 普通历史爱好者；
- 专业研究者；
- 自定义知识范围。

但是：

- 文学知识不等于正史知识；
- 记忆可能不准确；
- 历史一旦发生分歧，未来知识会逐渐失效；
- 历史知识不提供当前远方世界的实时状态。

“未来知识失效如何跟踪”属于 `[[汉末三国：历史参照与分歧]]` Expansion，不在此实现。

# 15. 历史人物引用规则

## 15.1 一人一卡

本资产族采用：

> **一位历史人物 = 一张 Character Card。**

World Pack 不复制完整人物档案。

## 15.2 World Pack 可以保存什么人物信息

为了描述世界事件，可以保存：

- 某人物在某世界级事件中担任公开历史角色；
- 某人物在某年份是否已经死亡；
- 某人物是否是当时公开政权的君主、主要统治者或公开官员；
- 创建历史快照所需的最小人物引用。

## 15.3 World Pack 不保存什么

不保存：

- 完整性格；
- 私密心理；
- 永久好感；
- 完整关系网；
- 所有个人经历的百科正文；
- 运行中的位置；
- 运行中的官职变化；
- 玩家进入后的命运。

## 15.4 时间实例化问题

同一人物在 184、200、208、220 年的：

- 年龄；
- 官职；
- 社会地位；
- 知识；
- 已发生经历；
- 人际关系；

差异巨大。

本 World Pack 只登记这个问题，不发明机器字段。

未来应由 Character Card + World 时间快照 + Runtime Bootstrap 共同产生对应年代的 Character State。

# 16. 玩家身份空间

## 16.1 历史人物

需要对应 Character Card。

规则：

- 接管前的已发生生涯成立；
- 接管后的主动选择归玩家；
- 世界不得强迫人物重演现实后续历史。

## 16.2 本地士人／官吏

可以来自：

- 地方士族；
- 普通读书家庭；
- 郡县吏员；
- 幕府与州郡属吏；
- 游学士人。

其社会机会应受出身、名望、地域和人脉影响。

## 16.3 豪族／家族成员

可以拥有较强地方基础，但也承担：

- 家族责任；
- 婚姻关系；
- 地方政治风险；
- 族人利益。

## 16.4 军旅身份

可以从普通士卒起步，也可以是已有军职或家兵背景。

是否拥有军权必须有明确来源。

## 16.5 商贾／工匠／医者

适合低至中层社会网络、地方经营与长期生活路线。

不能因为玩家不在官场就把整个国家历史排除在世界外；世界仍会发展，并通过税负、治安、战争、市场和迁徙影响其人生。

## 16.6 农户／流民／普通居民

适合强调：

- 生存；
- 家庭；
- 乡里；
- 迁徙；
- 征发；
- 战争间接影响；
- 从社会底层逐渐改变命运。

## 16.7 自建身份

自建身份必须符合：

- 所选年份；
- Region；
- 家世；
- 教育；
- 财产；
- 社会关系；
- 官职来源；
- 军事资源来源。

不允许无来源叠加：

> 顶级门第 + 巨额财富 + 天下名望 + 私兵万众 + 与所有名人熟识。

优势越大，越需要明确历史与社会来源。

## 16.8 现代穿越者

World Pack 只声明兼容这种 Player Character Definition。

具体：

- 穿越方式；
- 现代知识；
- 身体来源；
- 是否保留现代物品；
- 是否启用系统；

由玩家角色创建与可选 Expansion 继续定义。

# 17. 开局入口设计

## 17.1 原则

开局应由：

```text
时间锚点
+
玩家身份
+
合理初始 Region / Place
```

不得强迫所有玩家进入同一个“名场面”。

- 官僚；
- 士人；
- 宗室；
- 武官；
- 宫廷相关人物。

### 州郡地方

适合：

- 小吏；
- 士人；
- 豪族；
- 商人；
- 普通居民；
- 地方军政人物。

### 军营与前线

适合：

- 士卒；
- 将领；
- 护卫；
- 随军人员；

适合：

- 商贾；
- 工匠；
- 游侠；
- 医者；

# 18. 世界级公开事实与后台锁定事实

## 18.1 玩家可见公开事实

应根据年份、身份和所在地筛选，例如：

- 当前公开皇帝或政权；
- 当地公开官府；
- 当地广为人知的战争；
- 本地公开控制者；
- 社会上已经传播的名人声望；
- 当前时代的一般常识。

## 18.2 后台锁定世界事实

可以包括：

- 开局时间以前已经真实发生、但玩家角色并不知道的事件；
- 当前时间快照中真实存在但尚未传播到玩家所在地的远方公开事件；
- 真实地理与行政归属；
- 世界历史一致性需要维护、但角色尚未得知的客观事实。

## 18.3 禁止伪装成后台事实的内容

以下内容不能作为“后台锁定历史”预写：

- 某人物未来必然死亡；
- 某战役未来必然发生；
- 某人物未来必然称帝；
- 某人物必然背叛；
- 某政权必然灭亡；
- 玩家必然与某人物相爱；
- 司马氏必然统一天下。

## 18.4 NPC 私密事实

NPC 的：

- 私人目标；
- 情感；
- 秘密计划；
- 错误认知；
- 私人关系；

优先由 Character Card 与 Game State 持有，而非 World Pack。

# 19. 世界趋势与开放矛盾

> [!note] 趋势不是机制数值，也不是必然事件。

## 19.1 中央权威与地方权力

汉末的长期矛盾之一，是中央王朝名义与地方实际军事、财政和社会控制之间不断拉大。

不同时间节点中，这种矛盾可以表现为：

- 朝廷试图重新控制地方；
- 地方集团争夺朝廷名义；
- 军事人物借官职扩大独立性；
- 地方社会在多个政治权力之间选择依附。

## 19.2 正统与现实控制

“谁控制最多土地”与“谁被认为有资格代表天下”不是同一个问题。

王朝、汉室、宗室、禅让、帝号、官爵与实际军事力量之间长期存在张力。

## 19.3 人才流动

乱世会推动：

- 举荐；
- 征辟；
- 投奔；
- 逃亡；
- 易主；
- 隐居；
- 地方人才进入更大政治集团。

这些只是世界趋势；具体人才机制归政治 Expansion。

## 19.4 战争与民生

战争会对普通人产生长期影响。

即使玩家不参与争霸，也可能受到：

- 征发；
- 治安；
- 粮价；
- 市场；
- 迁徙；
- 疫病；
- 交通中断；
- 地方政权变化；

的影响。

## 19.5 地区分化

中原、河北、关中、荆州、巴蜀、江东、岭南和边地社会拥有不同的：

- 地理；
- 交通；
- 家族网络；
- 军事传统；
- 政治经验。

不能把三国写成只有三个颜色不同、内部完全同质的阵营。

- Skill mastery；
- Experience；
- Specialty；
- Character Execution Style；
- Creed；
- 五维 Canonical State。

消费本 World Pack 的：

消费本 World Pack 的：

- 世界级历史基线；

消费本 World Pack 的：

- 物质生活与正常生存条件；
- 战乱、迁徙与资源可得性背景；
- 地区环境、气候与旅行条件。

# 23. Runtime / Creator / asset-spec 需求登记

> [!note] 以下只是从本 World Pack 创作过程中暴露出的平台需求，不是假装已经存在的能力。

## 23.1 Game Runtime Requirements

### WR-01｜历史时间快照

创建游戏时需要能根据所选历史锚点建立时间相关的 Runtime Definition / Bootstrap。

### WR-02｜Region → Place → Scene

必须支持历史空间分层，并允许 Place 的名称、归属与政治意义随时间实例化。

### WR-03｜人物时间实例化

同一 Character Definition 需要根据世界时间产生合理的人物年龄、生涯进度和已发生经历边界。

### WR-04｜知识安全

远方历史事件、后台事实和现代玩家知识不能自动进入本地角色知识。

### WR-05｜历史过去冻结

开局以前已选择的历史基线必须成为本局既成过去；开局以后的原历史不得成为强制未来。

## 23.2 UI Host Requirements

### WH-01｜时间锚点选择

未来创建游戏流程需要能够展示：

- 年代；
- 一句话时代说明；
- 已发生重要变化；
- 适合的玩家身份类型。

### WH-02｜历史资料的玩家安全展示

UI 必须区分：

- 世界公开历史；
- 玩家角色已知；
- 现代穿越者可访问的历史参考；
- 玩家无权知道的后台事实。

## 23.3 asset-spec vNext Requirements

### WS-01｜World Pack 历史锚点语义

未来协议需要能够表达多个开局时间候选及其初始化信息，但具体字段尚未冻结。

### WS-02｜时间条件引用

Character Card / World Pack 必须能够安全协作产生不同时间的实例状态。

### WS-03｜跨资产引用

需要正式、可验证的跨资产引用机制，不能使用 Obsidian Wikilink 冒充机器 Ref。

### WS-04｜来源元数据

历史型资产未来最好能表达：

- 史实；
- 争议；
- 推断；
- 文学；
- 原创；

等来源类别。

## 23.4 Creator Requirements

### WC-01｜历史锚点编辑器

能够维护多个世界时间锚点，并检查时间顺序与世界事实冲突。

### WC-02｜历史人物覆盖预览

选择某锚点时，Creator 应能预览哪些 Character Card：

- 已出生；
- 适用；
- 已死亡；
- 尚不能实例化。

### WC-03｜地名时间预览

能够检查地名与政治归属是否与选定时代兼容。

### WC-04｜来源分层编辑

创作者可以标记史实、争议、推断、文学和原创，而不是把全部文字当成同一可信度。
